C-VISADOS 3.3.0 — GITHUB PAGES

1. Descomprima el ZIP.
2. Suba TODO el contenido descomprimido a la raíz del repositorio.
3. Deben verse directamente en la raíz: index.html, manifest.webmanifest, sw.js, css/, js/, data/, assets/.
4. Settings > Pages > Deploy from a branch > main > / (root).
5. Abra la URL HTTPS de GitHub Pages.
6. Para PWA, use Edge/Chrome y la opción Instalar C-VISADOS.

No suba solamente el ZIP y no coloque todo dentro de una carpeta adicional.
