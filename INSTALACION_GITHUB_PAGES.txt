C-VISADOS 3.4.0 — GITHUB PAGES

1. Descomprima C_VISADOS_REPOSITORIO_3.4.0.zip.
2. Suba TODO el contenido directamente a la raíz del repositorio.
3. Settings > Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
4. Abra la URL HTTPS publicada por GitHub Pages.
5. Si una instalación PWA anterior queda en caché, use “Revisar instalación” > “Reparar y recargar”.

La raíz debe contener directamente:
index.html
manifest.webmanifest
sw.js
.nojekyll
css/
js/
data/
assets/

No contiene BAT, PowerShell, EXE ni MSI.
