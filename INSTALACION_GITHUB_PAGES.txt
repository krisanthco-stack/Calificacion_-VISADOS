C-VISADOS 3.6.2 — INSTALACIÓN EN GITHUB PAGES

1. Descomprima el ZIP.
2. Suba TODO el contenido directamente a la raíz del repositorio GitHub.
3. En GitHub: Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: / (root).
7. Espere la publicación y abra la URL HTTPS.
8. Si continúa cargándose una PWA anterior, use en C-VISADOS: Revisar instalación > Reparar y recargar.

La raíz debe contener directamente:
index.html
manifest.webmanifest
sw.js
.nojekyll
css/
js/
data/
assets/

No subir el ZIP como único archivo ni crear una carpeta adicional alrededor del contenido.
