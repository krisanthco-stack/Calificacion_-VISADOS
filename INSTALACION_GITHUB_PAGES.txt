C-VISADOS 3.6.0 FINAL — GITHUB PAGES

1. Descomprima C_VISADOS_REPOSITORIO_FINAL_3.6.0.zip.
2. Suba TODO el contenido directamente a la raíz del repositorio GitHub.
3. Settings > Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
4. Abra la URL HTTPS publicada por GitHub Pages.
5. Si una instalación PWA anterior queda en caché, use “Revisar instalación” > “Reparar y recargar”.

La raíz debe contener directamente:
index.html
manifest.webmanifest
sw.js
.nojekyll
css/
js/
data/
assets/

MACHOTES DEFINITIVOS
- assets/templates/MACHOTE_APROBACION_DEFINITIVO.docx
- assets/templates/MACHOTE_RECHAZO_DEFINITIVO.docx
Los dos archivos se conservan byte por byte como fueron cargados.

No contiene BAT, PowerShell, EXE ni MSI.
