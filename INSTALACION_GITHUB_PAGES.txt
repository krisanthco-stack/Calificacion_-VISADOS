C-VISADOS 3.2.0 — PUBLICACIÓN EN GITHUB PAGES

1. Descomprima C_VISADOS_REPOSITORIO_3.2.0.zip.
2. Suba EL CONTENIDO del ZIP a la raíz del repositorio; no suba el ZIP como un único archivo.
3. En la raíz deben verse directamente:
   index.html
   manifest.webmanifest
   sw.js
   .nojekyll
   css/
   js/
   data/
   assets/
4. Settings > Pages > Deploy from a branch > main > / (root).
5. Abra la URL HTTPS de GitHub Pages y recargue una vez para recibir la nueva caché 3.2.0.
6. Instale desde C-VISADOS o desde el menú de Edge/Chrome.

No contiene BAT, PowerShell, EXE ni MSI.
